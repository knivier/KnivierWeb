What is Activerse?

Activerse is a Java 2D game framework for physics, graphics, and sound. Modular APIs let you customize the engine as much as the game.

A tool made by developers, for the developer.

v1.4.2 ships ActiverseEngine plus ActiverseUtils. Start from the wiki, or read Developers Insider Release 2 (PDF) for the clock, interpolation, and architecture.

Latest Version: v1.4.2

Timing, interpolation, and runtime hardening

v1.4.2 unifies the simulation clock, interpolates rendering between ticks, and loads assets from filesystem or classpath.

Unified clock for update and render, with missed-tick protection.
Tick interpolation for actors and camera between fixed updates.
ResourcePaths so packaged jars resolve images and sounds.
Keyboard helpers for edge detection and text input.
